# Timings Frequency Converter

Небольшое настольное приложение для пересчёта таймингов оперативной памяти
(из отчёта [ZenTimings](https://github.com/irusanov/ZenTimings)) с одной
частоты на другую с сохранением задержки в наносекундах.

Также доступна веб-версия (`index.html`) — работает прямо в браузере,
без установки, можно разместить на GitHub Pages.

## Возможности

- Импорт таймингов и исходной частоты прямо из html-отчёта ZenTimings
  (частота определяется автоматически из строки `Frequency`).
- Импорт CSV, ранее экспортированного этим же приложением.
- Ручной ввод: пустая таблица со стандартным списком таймингов —
  заполняете сами.
- Редактирование любого значения:
  - можно вводить число тактов напрямую;
  - можно вводить желаемое время в наносекундах — программа сама подберёт
    ближайший достижимый целый такт и обновит значение.
- Пересчёт новых таймингов на новую частоту в двух режимах:
  - **Безопасный** (по умолчанию) — округление в сторону "не хуже
    исходного": для обычных таймингов — не меньше исходной задержки,
    для `REFI` (чем больше, тем лучше) — наоборот, не больше исходной.
  - **Ближайшее значение** — просто минимальное отклонение по времени,
    без гарантии "не хуже".
- Экспорт результата в CSV через меню «Файл» → «Экспорт в CSV».

## Запуск из исходников

Требуется Python 3.8+ с `tkinter` (для GUI) и библиотека `beautifulsoup4`.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

pip install beautifulsoup4
python timings_gui.py
```

Веб-версию (`index.html`) отдельно устанавливать не нужно — просто
открыть файл в браузере.

## Сборка исполняемых файлов

- **Windows** — запустить `build_windows.bat`.
- **Linux** — запустить `./build_linux.sh` (нужны права на выполнение:
  `chmod +x build_linux.sh`).

Каждый скрипт сам создаёт отдельное виртуальное окружение под свою ОС,
ставит зависимости (`pyinstaller`, `beautifulsoup4`) и собирает бинарник.
Все служебные файлы сборки (venv, `build/`, `dist/`, `.spec`) складываются
в одну папку `_artifacts/`.

Готовые файлы появляются в:

```
_artifacts/builds/Timings.Converter.Windows.exe
_artifacts/builds/Timings.Converter.Linux
```

Чтобы собрать сразу обе версии с одной Windows-машины — можно вызвать
`build_linux.sh` через WSL (если он установлен) отдельной командой.

## Использование

1. **Файл → Открыть отчёт...** — выбрать html-отчёт ZenTimings. Частота и
   тайминги подставятся автоматически.
   **Файл → Открыть CSV...** — импортировать ранее экспортированный CSV.
   **Файл → Новый (ввести вручную)...** — начать с пустой таблицы и ввести
   всё самостоятельно.
2. При необходимости отредактировать значение — двойной клик по ячейке
   «Значение» или «нс» в любой из групп столбцов.
3. Указать целевую частоту (MT/s), выбрать режим округления и нажать
   «Пересчитать».
4. **Файл → Экспорт в CSV...** — сохранить таблицу.
